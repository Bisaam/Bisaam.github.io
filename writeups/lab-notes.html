Lab notebook

 A glimpse

While I work through a machine I keep a running notebook in CherryTree. Every box gets the same shape (recon, enumeration, vulnerabilities, exploitation, privilege escalation) so I can always retrace exactly how I got in. Here's a look at how I organise it, not a full walkthrough.

How it's organised

One structure, every machine

The notebook keeps the Web Security Academy work and the hands-on machines side by side. Each capstone box was taken to root; the note next to it is the route I used.

~/Web Security Lab
 Web Security Lab
├─ Web Security Academy   PortSwigger labs + notes
│  ├─ CSRF
│  ├─ Web LLM attacks
│  └─ Authentication
├─ Ethical Hacking        methodology · OSINT · buffer overflow
├─ Kioptrix               recon -> root
├─ vulnserver             Windows buffer overflow (custom Python)
└─ Course Capstone        5 machines, each taken to root
   ├─ Blue        Windows 7  · SMB EternalBlue
   ├─ Academy     Linux      · file upload -> writable cron
   ├─ Dev         Linux      · NFS loot -> sudo zip
   ├─ Butler      Windows 10 · Jenkins script console
   └─ BlackPearl  Linux      · Navigate CMS

Per machine, the same branches repeat so nothing slips through:

  • Reconnaissance
  • Enumeration
  • Vulnerabilities
  • Exploitation
  • Privilege escalation
